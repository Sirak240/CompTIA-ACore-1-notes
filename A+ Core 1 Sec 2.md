IP-Internet Protocol 
- When were sending information from a laptop to a server were using ethernet network.
- Information being sent across the network is the ethernet payload, the information at the
  beginning is the ethernet header and at the end ethernet trailer.

TCP and UDP
- They are both similar protocols used to transfer information.
- TCP and UDP allow us to communicate through multiple devices simultaneously sending
  information that might be different from each other. This is called multiplexing.
- Multiplexing allows us to send different types of traffic and have the proper
  information received on the other side.

TCP-Transmission Control Protocol
- This connection is referred as connection oriented
- There is a formal conversation to the device and a formal process to end the device
- This is like a phone call, you talk and on the other side there is a response
- Flow control is used by the receiving device telling the sender to speed up or slow down
  the data

UDP-User Datagram Protocol
- With the UDP we are connectionless
- No formal process of connection flow and no formal teardown process
  to end the communication (unreliable delivery)

Port Numbers
- This is used by TCP and UDP, its important when communicating with to a service
- Firewalls for the port numbers use TCP and UDP numbers to allow or block network traffic
- FTP-(File Transfer Protocol) TCP/20 and TCP/21 are both associated with FTP

SSH-Secure Shell
- SSH is used for when connecting to remote devices and configure changes
- It looks and acts the same as telnet

Telnet Protocol/SMTP-Simple Mail Transfer Protocol
- This communicates with TCP/23
- SMTP uses TCP/25 to send one email to another
- To receive email messages we use IMAP or POP3

DNS-Domain Name System/HTTP and HTTPS
- This converts names to IP addresses, an example www. Professormesser.com = 162.159.246.164
- Standard for of HTTP sends all HTTP data to a encrypted or clear communication
- HTTP uses port TCP/80 and HTTPS uses TCP/443
- TCP/443 uses a more secured version of HTTP, meaning the packet will be encrypted

POP3/IMAP
- receiving emails from an email server is POP3 which is one of the protocols
- POP3 is a protocol for basic mail transfer functions
- From the mobile device POP3 sends mail to your computer

802.11
- This allows you to connect wireless with devices such as bluetooth
- Using wireless headsets or speakers consists bluetooth
- Bluetooth uses 2.4 GHz range, the unlicensed ISM are frequencies that don't require
  special license to use them.
  ISM (Industrial, Scientific and Medical) allows us to turn on our devices using 802.11
  or bluetooth.
  802.11 allows us to move around the building and still have connection to the network.
  Bluetooth is more confined.

  DNS Server (Domain Name System)
  - it's not only responsible for resolving an IP address from a domain name
    it can provide the same information in reverse and more as well
  - DNS servers are primarily based on the domain name

  DHCP Server (Dynamic Host Configuration Protocol)
  - This is the protocol that can automatically assign IP address and other configuration
    settings anytime
  - Remembering IP addresses aren't needed, DHCP does that job for you
  - DHCP servers are very effective, when one isn't working there's others that can still
    provide IP addresses
  - The DHCP allows us to automatically accesses the system in the infrastructure. If you
    go into a coffee shop and connect right away thank DHCP

    DHCP Leases DORA
    - Administrators must know the process of the IP addresses being assigned
    - DORA stands for Discover, Offer, Request, and Acknowledge. This goes into affect
      when someone connects to the server each time
